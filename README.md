# write-diploma — навык для ИИ-агентов

Навык, который позволяет любому ИИ написать учебную или научную работу
(**ВКР / курсовая / НИР**) на Markdown-диалекте сервиса
[«Оформитель»](https://оформитель.com) (ГОСТ 7.32) и проверить её перед сдачей.

## Состав

```
write-diploma/
├── SKILL.md              # инструкции агенту: порядок работы и критические правила
├── references/
│   ├── dialect.md        # MD-диалект (таблицы, рисунки, формулы, источники…)
│   ├── Humanizer.md      # правила естественного текста (обязательны, против ИИ-клише)
│   ├── content.md        # требования к содержанию (структура, объём, разделы)
│   ├── safety.md         # необязательная глава «Безопасность и экологичность» (БЖД)
│   ├── economics.md      # необязательная глава «Экономическое обоснование» (ТЭО)
│   ├── profiles.md       # распознаваемые разделы и профили оформления
│   ├── fstec.md          # пример предметной области: защита персональных данных (ФСТЭК)
│   └── rules.md          # коды валидатора и способы их исправления
└── scripts/
    └── validate.py       # автономный валидатор (Python 3.8+, только стандартная библиотека)
```

Это именно **Agent Skill**, а не плагин Claude Code: установка — положить папку
`write-diploma/` туда, где агент ищет навыки. Манифест плагина не нужен — навыку
достаточно `SKILL.md` (плюс справочники и скрипт).

В распространяемом архиве всё лежит внутри папки `write-diploma/` (имя совпадает
с `name` во frontmatter). Тесты (`tests/`) не поставляются — они есть только в
репозитории.

## Как пользоваться

1. Агент читает `SKILL.md`, затем `references/Humanizer.md` (обязательно перед
   написанием) и пишет работу на диалекте (`references/dialect.md`; требования к
   содержанию — `references/content.md`).
2. Проверяет работу:

   ```bash
   python3 scripts/validate.py paper.md
   python3 scripts/validate.py paper.md --json
   python3 scripts/validate.py paper.md.zip     # если есть папка assets/
   ```

   Код выхода `0` — жёстких ошибок нет; `1` — есть `hard-error` (сборка не пройдёт).
3. Исправляет документ по замечаниям (`CODE @ line N: message`) и целиком
   выводит его заново.
4. Возвращает `paper.md` (или `paper.md.zip` с `assets/`).

В конце работы агент **обязан написать**, что дальше файл нужно загрузить на
[оформитель.com](https://оформитель.com) и там сформировать DOCX/PDF:

- обычный `paper.md` — открыть через меню «Файл → Открыть» или загрузить из
  личного кабинета;
- `paper.md.zip` — загрузить архивом, сервис сам разложит картинки;
- в сервисе выбрать профиль ГОСТ 7.32 и собрать DOCX/PDF.

## Установка в разных агентах

Agent Skill — это просто папка с `SKILL.md`. Куда её положить:

- **Claude Code / claude.ai** — `~/.claude/skills/write-diploma/` (личная) или
  `.claude/skills/write-diploma/` (в проекте). *(Чтобы оформить навык как
  **плагин** Claude Code, понадобился бы `.claude-plugin/plugin.json` и навык в
  `skills/<name>/SKILL.md` — другая раскладка; здесь обычный навык.)*
- **opencode / агенты в стиле Codex** — `~/.agents/skills/write-diploma/` или
  `.agents/skills/` проекта.
- **Любой другой агент** — укажите ему на папку: инструкции в `SKILL.md`,
  справочники в `references/`, скрипт в `scripts/`. Достаточно Python 3.8+, без
  внешних зависимостей и без доступа к сервису.

## Зависимости

Только стандартная библиотека Python. Ни PyYAML, ни движка рендеринга.
